# ELK Stack (Elasticsearch & Kibana) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Integrate Kibana into the infrastructure stack and configure Serilog to stream structured JSON logs directly to Elasticsearch for centralized logging and visualization.

**Architecture:** Add Kibana (port 5601) to `docker-compose.infra.yml` linked to Elasticsearch (port 9200), install `Elastic.Serilog.Sinks` in `Vendor.Api`, and configure automated daily log indices (`vendor-api-logs-{yyyy.MM.dd}`).

**Tech Stack:** ASP.NET Core 9, Serilog, Elastic.Serilog.Sinks, Docker Compose, Elasticsearch 8.13.4, Kibana 8.13.4.

## Global Constraints

- Elasticsearch Host: `http://localhost:9200`
- Kibana Port: `5601`
- Log Index Format: `vendor-api-logs-{yyyy.MM.dd}`

---

### Task 1: Update Infrastructure Stack with Kibana

**Files:**
- Modify: `docker-compose.infra.yml`

- [ ] **Step 1: Update `docker-compose.infra.yml`**

Ensure `kibana` service is present under `services`:

```yaml
  kibana:
    image: docker.elastic.co/kibana/kibana:8.13.4
    container_name: vendor-kibana
    restart: unless-stopped
    ports:
      - "5601:5601"
    environment:
      - ELASTICSEARCH_HOSTS=http://elasticsearch:9200
    depends_on:
      elasticsearch:
        condition: service_healthy
```

- [ ] **Step 2: Start container stack**

Run: `docker compose -f docker-compose.infra.yml up -d`
Expected: `vendor-kibana` created and running alongside `vendor-elasticsearch`, `vendor-mssql`, `vendor-redis`.

- [ ] **Step 3: Commit**

```bash
git add docker-compose.infra.yml
git commit -m "feat(infra): add kibana 8.13.4 container to infrastructure compose file"
```

### Task 2: Install `Elastic.Serilog.Sinks` and Configure Serilog

**Files:**
- Modify: `src/Vendor.Api/Vendor.Api.csproj`
- Modify: `src/Vendor.Api/appsettings.json`
- Modify: `src/Vendor.Api/appsettings.Development.json`

- [ ] **Step 1: Install NuGet Package**

Run: `dotnet add src/Vendor.Api/Vendor.Api.csproj package Elastic.Serilog.Sinks`

- [ ] **Step 2: Update `appsettings.json` and `appsettings.Development.json`**

Update `Serilog` configuration block to include the `Elasticsearch` sink:

```json
{
  "Serilog": {
    "Using": [ "Serilog.Sinks.Console", "Elastic.Serilog.Sinks" ],
    "MinimumLevel": {
      "Default": "Information",
      "Override": {
        "Microsoft": "Warning",
        "Microsoft.Hosting.Lifetime": "Information",
        "Hangfire": "Information"
      }
    },
    "WriteTo": [
      { "Name": "Console" },
      {
        "Name": "Elasticsearch",
        "Args": {
          "nodes": [ "http://localhost:9200" ],
          "indexFormat": "vendor-api-logs-{0:yyyy.MM.dd}"
        }
      }
    ],
    "Enrich": [ "FromLogContext", "WithMachineName", "WithThreadId" ]
  }
}
```
