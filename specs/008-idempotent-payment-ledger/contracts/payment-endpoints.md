# API Contract: Idempotent Payment Endpoints

**Feature Branch**: `008-idempotent-payment-ledger`
**Date**: 2026-07-29

This document specifies the REST endpoint contracts for processing payments with mandatory idempotency keys, retrieving payment timeline ledgers, and ingesting signed webhooks.

---

## 1. Process Payment Endpoint

### Request
`POST /api/v1/payments/process`

#### Headers
| Header Name | Type | Required | Description |
|-------------|------|----------|-------------|
| `Idempotency-Key` | `UUID` | **Yes** | Client-generated UUID v4 token (e.g. `9b1deb4d-3b7d-4bad-9bdd-2b0d7b3dcb6d`) |
| `Content-Type` | `string` | **Yes** | `application/json` |

#### Request Body
```json
{
  "orderId": "3fa85f64-5717-4562-b3fc-2c963f66afa6",
  "amount": 149.99,
  "currency": "USD",
  "paymentMethod": "CreditCard",
  "providerName": "Stripe"
}
```

---

### Response Specifications

#### 201 Created (Initial Payment Success)
```json
{
  "paymentId": "7c9e6679-7425-40de-944b-e07fc1f90ae7",
  "orderId": "3fa85f64-5717-4562-b3fc-2c963f66afa6",
  "status": "Authorized",
  "amount": 149.99,
  "currency": "USD",
  "gatewayReferenceId": "pi_3MtwBwLkdIwHu7ix28a3tqsm",
  "idempotencyKey": "9b1deb4d-3b7d-4bad-9bdd-2b0d7b3dcb6d",
  "createdAtUtc": "2026-07-29T14:40:00Z"
}
```

#### 200 OK (Idempotent Duplicate Replay)
*Returns the exact cached response body and headers recorded from the primary execution.*

#### 400 Bad Request (Missing or Invalid Idempotency Key)
```json
{
  "type": "https://tools.ietf.org/html/rfc7231#section-6.5.1",
  "title": "Validation Error",
  "status": 400,
  "errors": {
    "Idempotency-Key": [
      "The Idempotency-Key header is required and must be a valid UUID v4."
    ]
  }
}
```

#### 422 Unprocessable Entity (Idempotency Payload Mismatch)
```json
{
  "type": "https://tools.ietf.org/html/rfc4918#section-11.2",
  "title": "Unprocessable Entity",
  "status": 422,
  "detail": "The payload parameters for idempotency key '9b1deb4d-3b7d-4bad-9bdd-2b0d7b3dcb6d' do not match the original request payload."
}
```

## 3. Asynchronous Webhook Ingestion Endpoint

### Request
`POST /api/v1/payments/webhooks/{providerName}`

#### Headers
| Header Name | Description |
|-------------|-------------|
| `Stripe-Signature` (or provider equivalent) | Cryptographic signature header generated by payment provider |

---

### Response Specifications

#### 200 OK (Event Verified & Processed / Duplicate Skipped)
```json
{
  "eventId": "evt_1MtwBwLkdIwHu7ix999a",
  "status": "Processed"
}
```

#### 401 Unauthorized (Invalid Signature)
```json
{
  "title": "Unauthorized",
  "status": 401,
  "detail": "Invalid cryptographic webhook signature."
}
```
